# **App Name**: Lifeline Alert

## Core Features:

- Secure User Authentication: Implements secure login and registration using email/phone number and OTP verification.
- User Profile Management: Allows users to create and manage their profile, including name, vehicle number, blood group, and emergency contact details.
- Accident Detection System: Utilizes vehicle-mounted sensors (accelerometer, gyroscope, crash detection sensors) to automatically detect accidents based on sensor data thresholds.
- Automated Emergency Alert: Automatically triggers an emergency alert upon severe accident detection, instantly sending notifications to the nearest ambulance office/emergency response center and registered emergency contacts via real-time push notifications.
- Manual SOS Activation: Provides a manual SOS button within the app, allowing users to manually trigger an emergency alert if conscious.
- Real-time Location Tracking and Display: Integrates Google Maps to track the accident spot in real-time via GPS and display the accident location on the map.
- Ambulance/Admin Dashboard: Provides a dedicated login and live dashboard for ambulance staff/admins, showcasing accident alerts, map view with distance and estimated arrival time, and status updates (Ambulance Dispatched/On the Way/Reached).

## Style Guidelines:

- Primary color: A vivid blue (#29ABE2) to convey trust and immediacy, mirroring emergency services.
- Background color: A light, desaturated blue (#E0F7FA) providing a clean and calm backdrop.
- Accent color: A striking orange (#FF9800) used for the SOS button and critical alerts to draw immediate attention.
- Font pairing: 'Space Grotesk' (sans-serif) for headings and 'Inter' (sans-serif) for body text, providing a modern, easily readable interface.
- Simple, universal icons (e.g., location pin, ambulance, phone) for quick recognition, designed with high contrast for visibility in urgent situations.
- Clean and intuitive layout with high-contrast elements; large, easy-to-tap buttons and minimal text to ensure accessibility and rapid interaction during emergencies.
- Subtle animations used for loading indicators and status updates; noticeable attention-grabbing animations are used only when actively triggered by alerts.
